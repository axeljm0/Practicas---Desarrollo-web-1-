¡Ojo con getMonth() en JavaScript!: Los meses en el objeto Date tienen índice base cero (0 = Enero, 1 = Febrero ... 11 = Diciembre). Por ello, para mostrar el mes a un usuario humano siempre se debe sumar + 1.
