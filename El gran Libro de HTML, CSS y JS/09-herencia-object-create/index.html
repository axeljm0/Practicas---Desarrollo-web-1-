Ejercicio 09: Herencia con Object.create()

Métodos compartidos: hacerSonido(), dormir()
Propiedad compartida: esSerVivo = true
▲ hereda vía Object.create(animal)
Objeto Derivado: perro
Propiedades propias: nombre = "Firulais", raza = "Golden Retriever"
Método propio: ladrar() | Sobrescritura: hacerSonido()
