¿Cómo funciona 'this' en un método?

Cuando se invoca vehiculo.descripcion(), la palabra clave this apunta automáticamente al objeto que se encuentra a la izquierda del punto (en este caso, vehiculo). De este modo, this.marca accede a la propiedad marca de ese objeto en concreto.
