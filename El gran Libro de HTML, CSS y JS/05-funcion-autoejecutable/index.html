Ejercicio 05: Función Autoejecutable (IIFE)

Patrón IIFE (Immediately Invoked Function Expression) para calcular el área de un círculo con Math.PI encapsulando el ámbito.

Sintaxis: (function() { /* código encapsulado */ })();
Se ejecuta inmediatamente tras su definición y previene la contaminación del objeto global (window).
r = 5
Radio actual
5 cm
Área del círculo
78.54 cm²
Auditoría del Ámbito Global (Window)
Variable interna PI_LOCAL en window: undefined (Protegida)
Función calcularAreaCirculo directa en window: undefined (Encapsulada)
