¿Cómo funciona internamente?: Los temporizadores de JavaScript no bloquean el hilo principal. Son delegados a las Web APIs del navegador, las cuales colocan el callback en la cola de tareas (*Task Queue*) para que el *Event Loop* lo ejecute cuando el tiempo se cumpla.
