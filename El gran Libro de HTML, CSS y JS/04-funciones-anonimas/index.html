Ejercicio 04: Funciones Anónimas

Expresiones de función (Function Expressions) y asignación a variables con const elevarAlCuadrado = function(numero) { ... }.

Concepto clave: Una función anónima no tiene nombre propio. Se almacena en una variable o se pasa como argumento (*callback*), tratando a las funciones como valores de primera clase.
